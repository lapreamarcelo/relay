The native app captures show sample matches. They are separate captures, not a recording of live synchronization.

## Reproduce

From the Relay repository root, run:

```sh
node --experimental-transform-types docs/demos/racketly-2026-10-09/render.mjs
```

The script uses Relay's production timeline normalization, device mesh engine, label animation, camera, audio processing, and video renderer. Its media and storage adapters resolve to the files in this directory, so rendering writes local artifacts without uploading media or modifying a cloud project. The media URLs in `timeline.json` are local demo placeholders; to save it as a normal Relay project, upload the source assets and replace those URLs.

`racketly-relay-demo-real-watch.mp4` is the revised export. `racketly-relay-demo.mp4` is the superseded procedural-Watch version. `relay-editor.png` shows the revised timeline open in the Relay editor with local demo API fixtures. `verification.json` records the revised exported file's media metadata. Racketly's source files were read and copied; its project was not modified.

## Optional 3D showcase — 9 October

`racketly-relay-demo-3d.mp4` is a 12-second landscape, 1920×1080, 24 fps H.264/AAC export through Relay's production FFmpeg and Chromium scene renderer. It opens with the actual Watch recording, then combines the licensed 3D Watch Ultra 2 and iPhone 15 Pro Max with existing Racketly screen images. The devices hold static frontal poses before the timeline's explicit rotation keys. New GPU frames default to still poses.

Reproduce locally after building the renderer bundle:

```sh
node apps/web/scripts/build-gpu-renderer.mjs
node --experimental-transform-types docs/demos/racketly-2026-10-09/render-gpu.mjs
```

`render-gpu.mjs` uses local input bytes and an isolated storage adapter; it never publishes media. The exact editable project is `timeline-gpu.json`. Model credits are in `apps/web/public/devices/ATTRIBUTION.json`. The Watch mesh represents Ultra 2, rather than the previous Ultra 3 frontal PNG artwork.

`relay-editor-3d.png` shows the landscape project in Relay, with GPU rendering, model attribution, the Still motion option, and the explicit 3D rotation controls. The screenshot uses local demo API/media fixtures.

The bezel-quality revision uses multisampled postprocessing buffers and a display-density-aware preview capped at 1920 pixels. `racketly-relay-demo-3d-sharp.mp4` is a review copy of the updated 1080p export; `devices-3d-sharp.png` is its 6.2-second frame. The editor screenshot was refreshed at 2× display density. Rotation remains authored explicitly and is not generated by model selection.
